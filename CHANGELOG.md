# Changelog

All notable changes to `laravel-extended-validation` will be documented in this file.

## 1.0.0 - 2024-XX-XX

- Initial release with 15 validation rules
- Slug, EvenNumber, OddNumber, Semver, HexColor
- Base64String, Luhn, MinWords, MaxWords
- Domain, E164Phone, Isbn, CountryCode
- WithoutAlias, NotEmail
- Full test suite with Pest
- String rule, Rule macro, and class syntax support
